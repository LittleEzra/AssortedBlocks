*Note: This update contains a potentially dangerous change.* **! Make a backup of your worlds before updating !**

## Added:
- Stone Lantern
- Calcite Pillar
- Snow and Ice Block Sets
- New Painted Calcite Variants
    - Scarlet Calcite
    - Sunny Calcite
    - Verdant Calcite
    - Rose Calcite
- Book Pile
- Crystal Ball
## Changes:
- Renamed Painted Calcite blocks to Azure Calcite
    - It should be able to update old worlds correctly, but you should probably still make a backup
- Allowed for removing the support of String Lights by right-clicking them, making them droop.
- Allowed wet sponges and wool to remove paint from Painted Pots
- Made Tall Candles brighter
- Removed String Lights connecting to other blocks.
    - Feedback is appreciated on this; this change can also be modified with the block/connects_to_string_lights tag
## Fixes:
- Fixed being able to add a candle to stacked tall candles even when you do not have enough
- Added a few missing recipes
